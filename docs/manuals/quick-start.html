Smart Signage v1.6.0

Quick Start — 디지털 사이니지 운영 1쪽 요약 매뉴얼

1. 시스템 개요

구성

  • 1번 모니터: 편집기 (Editor UI)
  • 2+3+4번 모니터: 사이니지 출력 (NVIDIA Surround 5760×1080/1200)
  • HDMI Matrix: PN-8080 (8×8, TCP/8000) — 선택

주요 포트

  • 3000 — Next dev 서버 (개발 시)
  • 7321 — 내장 HTTP (LAN 다중 클라이언트)
  • 8000 — PN-8080 매트릭스 ASCII

2. 시작하기

  1. 바탕화면의 Smart Signage 아이콘 실행 → 1번 모니터에 편집기 표시.
  2. 좌측 슬라이드 목록에서 슬라이드 작성 또는 템플릿 선택.
  3. 우측 Preview 아래 사이니지에 표시 클릭 → 2+3+4번 모니터로 출력 송출.
  4. PlaybackControls에서 ◀ / ⏸ / ▶ 또는 단축키로 페이지 전환.

3. 슬라이드 단축키

동작키
다음 페이지Space · → · ↓ · PageDown · Enter · N
이전 페이지Backspace · ← · ↑ · PageUp · P
첫 페이지 / 마지막Home / End
재생 / 일시정지 토글S
편집기 전체화면F11
텍스트 편집 중에는 단축키가 자동으로 비활성화되어 키 입력이 그대로 텍스트에 들어갑니다.

4. 매트릭스 제어 (v1.5+)

  1. 우측 매트릭스 제어 헤더 ▶ 클릭 → 펼치기.
  2. IP 192.168.10.199, 포트 8000 입력 → 연결.
  3. 입력 셀 선택 → 출력 셀 클릭 = 즉시 라우팅 (Auto-Take).
  4. 자주 쓰는 조합은 프리셋 + 로 저장 → 한 번 클릭으로 일괄 적용.
  5. 프리셋 우클릭 → 확인 → 삭제 + 자동 재정렬.

5. 운영 옵션 / 화면 정리

접기/펴기 (v1.6)

  • 운영 옵션, 매트릭스 제어 헤더의 ▼/▶ 클릭으로 본문 토글.
  • 앱 재시작 시 기본 접힘 상태로 복귀.

주요 옵션

  • signage.resolution 5760×1080 / 5760×1200
  • signage.mode Surround / Individual (×3 타일)
  • slide.transitionSec 페이지 전환 fade(초)
  • slide.padding 슬라이드 여백(px)

6. 트러블슈팅

증상조치
"사이니지에 표시" 클릭 후 컨트롤이 늦게 뜸5760×1200에서 첫 클릭 시 지연될 수 있음 — 2~3초 대기 또는 다시 클릭.
fade 1초 설정 시 검은 배경이 보임v1.3.0 이후 true crossfade 적용. 검은색 보이면 업데이트 확인.
매트릭스 "끊김" 표시 + 자동 재연결 실패네트워크/IP/포트 확인 → 연결 해제 후 다시 연결.
프리셋 + 버튼 비활성매트릭스 미연결 상태 — 연결 후 자동 활성화.
